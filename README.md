How to make your life easier next time:

You don’t have to type out those long file paths every time. 
Here is the fastest way to start it up in the future:

Open your terminal.Type cd  (with a space after it).
Open your Downloads folder in Finder, grab the mongodb-macos-x86_64-7.0.40 folder, and drag and drop it directly into your terminal window. The terminal will automatically type out the whole hidden path for you.Add /bin to the end of that path and press

 Enter.Run the start command:bash
 ./mongod --dbpath ~/mongodb-data
